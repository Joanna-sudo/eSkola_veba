Operatori

Operatori su specijalni simboli pomoću kojih se nad promenljivama i vrednostima izvršavaju određene operacije, kao što su sabiranje, poređenje, kombinovanje logičkih uslova i slično.

1. Aritmetički operatori

Koriste se za osnovne matematičke operacije.

Operator Značenje Primer
+ sabiranje 7 + 2 → 9
- oduzimanje 7 - 2 → 5
* množenje 7 * 2 → 14
/ deljenje (rezultat je float) 7 / 2 → 3.5
// celobrojno deljenje 7 // 2 → 3
% ostatak pri deljenju 7 % 2 → 1
** stepenovanje 7 ** 2 → 49
Primer 1 (Aritmetički operatori): Nad dva broja izračunati i ispisati zbir, količnik, celobrojni količnik, ostatak pri deljenju i stepen. a = 17 b = 4 print(a + b) # 21 print(a / b) # 4.25 print(a // b) # 4 print(a % b) # 1 print(a ** b) # 83521
Ako se dolazi iz drugih programskih jezika ili iz matematike, važno je zapamtiti da se u Pythonu stepenovanje piše **, nikako ^. Znak ^ u Pythonu ima potpuno drugo značenje (bitovska operacija XOR) i ne koristi se za stepenovanje.

2. Operatori dodele

Osim osnovnog operatora =, kojim se promenljivoj dodeljuje vrednost, Python nudi i složene operatore dodele. Oni u jednom koraku kombinuju aritmetičku operaciju i dodelu rezultata istoj promenljivoj (npr. +=, -=, *=, /=, //=, %=, **=).

Primer 2 (Složeni operatori dodele): Promenljivoj uvećati vrednost korišćenjem složenih operatora dodele += i *=. broj = 10 broj += 5 # isto kao broj = broj + 5 print(broj) # 15 broj *= 2 # isto kao broj = broj * 2 print(broj) # 30

3. Operatori poređenja

Vraćaju logičku vrednost True ili False, u zavisnosti od toga da li je uslov ispunjen.

Operator Značenje Primer
== jednako 5 == 5 → True
!= različito 5 != 3 → True
> veće 5 > 3 → True
< manje 5 < 3 → False
>= veće ili jednako 5 >= 5 → True
<= manje ili jednako 3 <= 5 → True
Primer 3 (Poređenje vrednosti): Uporediti dva broja operatorima jednakosti i „manje od“. a = 10 b = 15 print(a == b) # False print(a < b) # True
Važno je ne pomešati = i ==. Jedan znak jednakosti (=) je operator dodele. Njime se promenljivoj dodeljuje vrednost (npr. a = 10). Dva znaka jednakosti (==) čine operator poređenja. Njime se proverava da li su dve vrednosti jednake i kao rezultat se dobija True ili False (npr. a == 10).

4. Logički operatori

Koriste se za kombinovanje više logičkih uslova.

Operator Značenje Opis Primer
and logičko I (konjunkcija) daje rezultat True samo ako su oba operanda True True and False → False
or logičko ILI (disjunkcija) daje rezultat True ako je bar jedan operand True True or False → True
not logičko NE (negacija) obrće logičku vrednost operanda not True → False
Primer 4 (Logički operatori): Proveriti da li osoba ispunjava uslov za vožnju (dovoljno godina i poseduje vozačku dozvolu) korišćenjem logičkih operatora. godine = 20 ima_dozvolu = True print(godine >= 18 and ima_dozvolu) # True print(not ima_dozvolu) # False

5. Operatori pripadnosti

Operatorom in proverava se da li se neka vrednost nalazi unutar kolekcije (niske, liste, torke...). Rezultat provere je logička vrednost True ili False. Operator not in radi obrnuto, odnosno rezultat provere je True kada vrednost nije deo kolekcije.

Operator Značenje Primer
in pripada (nalazi se u kolekciji) "a" in "Ana" → True
not in ne pripada (nije u kolekciji) 5 not in [1, 2, 3] → True
Primer 5 (Operatori pripadnosti): Proveriti da li se dati karakter nalazi u niski i da li se dato ime nalazi u listi. ime = "Marko" spisak = ["Ana", "Jovana", "Petar"] print("k" in ime) # True print("Marko" in spisak) # False print("Marko" not in spisak) # True

6. Operatori identiteta

Operatorom is proverava se da li dve promenljive ukazuju na isti objekat u memoriji (a ne samo da li imaju jednake vrednosti). Operator is not je njegova negacija. U praksi se najčešće koriste za proveru da li promenljiva ima „nikakvu“ vrednost, odnosno da li je jednaka None.

Operator Značenje Primer
is isti objekat u memoriji vrednost is None → True
is not nije isti objekat u memoriji ime is not None → True
Primer 6 (Operatori identiteta): Proveriti da li promenljiva ima vrednost None. vrednost = None ime = "Ana" print(vrednost is None) # True print(ime is not None) # True
Za poređenje vrednosti koristi se ==, dok is poredi identitet (da li je reč o istom objektu u memoriji). Van provere sa None, u početnom radu skoro uvek treba koristiti ==.

Pored svih navedenih, Python ima i bitovske operatore (&, |, ^, ~, <<, >>), koji rade nad pojedinačnim bitovima celih brojeva. Oni se u svakodnevnom radu koriste znatno ređe i ovde se ne obrađuju detaljno.
Zadaci:

1. Napraviti promenljive a i b sa dva cela broja i ispisati njihov zbir, razliku, proizvod i količnik.

2. Za dva zadata broja ispisati rezultate poređenja: da li su jednaki, da li je prvi veći od drugog i da li je prvi broj paran (deljiv sa 2 bez ostatka).

3. Za zadati broj sekundi izračunati i ispisati koliko je to punih minuta i koliko sekundi preostaje (operatori // i %). Pomoću logičkog operatora dodatno ispisati da li je uneti broj veći od jednog sata (3600 sekundi).
