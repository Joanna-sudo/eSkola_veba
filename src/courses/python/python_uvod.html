Uvod u Python

Python je programski jezik opšte namene koji je krajem 1980-ih osmislio Gvido van Rosum (Guido van Rossum), a čija je prva zvanična verzija objavljena 1991. godine. Od tada se neprestano razvija i danas spada u red najpopularnijih programskih jezika na svetu. Zanimljivo je da jezik nije dobio ime po zmiji, kako mnogi pretpostavljaju, već po britanskoj komičarskoj grupi Monty Python i njihovoj emisiji "Monty Python's Flying Circus", čiji je veliki obožavalac bio Gvido van Rosum. Zmija se ipak odomaćila kao nezvanični simbol Pythona i danas se često pojavljuje u njegovom logotipu.

Jedna od njegovih osnovnih osobina je to što je interpretirani jezik. To znači da se napisani kod ne prevodi (kompajlira) unapred u mašinski jezik, već ga u trenutku pokretanja programa izvršava poseban program koji se naziva Python interpreter. Zbog toga se kod može odmah pokrenuti i isprobati, bez dodatnog koraka kompajliranja koji postoji kod mnogih drugih programskih jezika.

Pored toga, Python je i dinamički tipiziran jezik. To znači da tip podatka (broj, tekst, tačno/netačno...) nije potrebno unapred navoditi. Python automatski određuje tip na osnovu vrednosti sa kojom radimo. Kasnije ćemo videti kako se takve vrednosti čuvaju u promenljivama i kako se sa njima radi.

Upravo zahvaljujući ovakvim osobinama, a pre svega jednostavnoj i čitljivoj sintaksi koja podseća na prirodan engleski jezik, Python se danas često preporučuje kao prvi programski jezik za učenje.

Primena Pythona

Zahvaljujući ogromnom broju gotovih biblioteka, Python se danas koristi u mnogim oblastima:

  • razvoj veb aplikacija (korišćenjem okvira kao što su Django i Flask)
  • automatizacija zadataka (pisanje skripti za obradu fajlova, rad sa dokumentima i automatizaciju ponavljajućih poslova)
  • obrada i analiza podataka (korišćenjem biblioteka kao što su NumPy i Pandas)
  • mašinsko učenje i veštačka inteligencija (pomoću biblioteka kao što su scikit-learn, TensorFlow i PyTorch)
  • naučni i inženjerski proračuni
  • razvoj desktop aplikacija i igara

Prednosti i nedostaci Pythona

Neke od najvažnijih prednosti Pythona su:

  • pogodan je za početnike, ali i dovoljno moćan za profesionalnu upotrebu
  • veliki broj besplatnih biblioteka i alata
  • velika i aktivna zajednica programera
  • podrška za sve popularne operativne sisteme (Windows, macOS i Linux)

Kao jedan od nedostataka često se navodi manja brzina izvršavanja u poređenju sa nekim kompajliranim jezicima, kao što su C i C++. Međutim, u velikom broju praktičnih primena ova razlika nije presudna, dok prednosti jednostavnosti i brzine razvoja često imaju veću važnost.

Ovaj kurs obuhvata osnove Pythona, od instalacije i prvog programa, preko promenljivih, uslova, petlji, funkcija, klasa i objekata, do rukovanja greškama i rada sa tekstualnim, JSON i CSV fajlovima. Kurs se završava praktičnim lekcijama u kojima se automatski čitaju i menjaju podaci u Excel tabelama, prikazuje statistika i grafici, kao i čita i menja sadržaj Word dokumenata.
