Instalacija i podešavanje okruženja

Da bi se pisali i pokretali Python programi na računaru, neophodno je instalirati Python interpreter. Sam kod se može pisati u bilo kom tekst editoru, ali se u praksi preporučuje korišćenje IDE-a (integrisanog razvojnog okruženja), jer takav program prepoznaje Python sintaksu i znatno olakšava pisanje, pokretanje i pronalaženje grešaka u kodu.

1. Preuzimanje i instalacija Pythona

Instalacija se preuzima sa zvaničnog sajta python.org/downloads. Sajt automatski prepoznaje operativni sistem i nudi odgovarajući instalacioni fajl.

Na Windows operativnom sistemu, prilikom instalacije štiklirati opciju „Add Python to PATH“. Na taj način se Python komanda može pozvati iz bilo kog foldera preko komandne linije, bez unošenja pune putanje do instalacije.

2. Provera instalacije

Nakon instalacije, otvara se komandna linija (na Windows-u cmd ili PowerShell, na macOS/Linux-u terminal). Na Windows-u se komandna linija najlakše pronalazi preko pretrage u Start meniju, unosom reči cmd:

U komandnoj liniji se zatim unosi sledeća komanda:

python --version

Ukoliko je instalacija uspešna, u konzoli će se ispisati instalirana verzija, na primer Python 3.14.7, kao na slici ispod:

Zajedno sa Pythonom se instalira i pip - alat za instaliranje dodatnih biblioteka, koji ćemo koristiti u kasnijim lekcijama. Njegovu instalaciju možemo proveriti na sličan način.

pip --version

3. Izbor editora

Python programi se čuvaju u datotekama sa ekstenzijom .py. Kod se može pisati u bilo kom tekst editoru, ali je za rad sa Pythonom praktičnije koristiti specijalizovane programe koji pružaju podršku za pisanje, pokretanje i debagovanje koda. Među njima su Visual Studio Code (VS Code) i PyCharm, dok se za jednostavniji rad može koristiti i Notepad++. Za brzo isprobavanje kraćih naredbi može se koristiti i IDLE, jednostavno razvojno okruženje koje se automatski instalira zajedno sa Pythonom.

Ukoliko se za rad koristi Visual Studio Code (VS Code), potrebno je u okviru njega instalirati i zvaničnu Python ekstenziju (Microsoft), koja omogućava prepoznavanje sintakse, pokretanje i debagovanje Python koda. Ekstenzija se instalira tako što se prvo klikne na ikonicu Extensions u bočnoj traci (označeno sa 1 na slici), zatim se u polje za pretragu ukuca pojam python, i na kraju se pored zvanične Python ekstenzije (Microsoft) klikne dugme Install (označeno sa 2 na slici):

Zadatak: Instalirati Python na svom računaru i u komandnoj liniji proveriti instaliranu verziju pomoću komande python --version. Po želji instalirati i VS Code.
