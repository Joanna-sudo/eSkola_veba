Rad sa JSON i CSV fajlovima

Pored običnog teksta, podaci se veoma često čuvaju i razmenjuju u dva standardizovana formata: JSON, pogodan za strukturirane podatke (rečnike i liste), i CSV, pogodan za tabelarne podatke (redove i kolone). Za oba formata Python ima ugrađene module, pa nije potrebna nikakva dodatna instalacija.

Kao u prethodnoj lekciji, fajlovi mogu da se otvore pomoću funkcije open() i naredbe with, u režimu "r" za čitanje, odnosno "w" za pisanje. Za JSON i CSV podatke sadržaj se može obrađivati pomoću funkcija i objekata iz modula json i csv, koji omogućavaju da se podaci automatski pretvore u odgovarajuće Python strukture.

1. Upisivanje podataka u JSON fajl

Modul json omogućava direktno pretvaranje Python rečnika (ili liste) u JSON zapis, i obrnuto. Funkcija dump() upisuje podatke u fajl.

Primer 1 (Upisivanje rečnika u JSON fajl): Sačuvati rečnik koji predstavlja osobu u JSON fajl. import json osoba = {"ime": "Saša", "godine": 25, "grad": "Beograd"} with open("osoba.json", "w", encoding="utf-8") as fajl: json.dump(osoba, fajl, ensure_ascii=False, indent=4)
Parametar ensure_ascii=False obezbeđuje da se naša slova (č, ć, ž, š, đ) upišu čitljivo, umesto da budu zamenjena kodovima. Parametar indent=4 podešava uvlačenje, radi preglednijeg zapisa.

2. Čitanje podataka iz JSON fajla

Funkcija load() radi obrnuto od funkcije dump(). Ona učitava sadržaj JSON fajla i pretvara ga nazad u odgovarajuću Python strukturu (rečnik ili listu).

Primer 2 (Čitanje JSON fajla): Učitati podatke o osobi iz JSON fajla, uz obradu slučaja kada fajl ne postoji. import json try: with open("osoba.json", "r", encoding="utf-8") as fajl: osoba = json.load(fajl) print(osoba["ime"], "-", osoba["godine"], "godina") except FileNotFoundError: print("Fajl 'osoba.json' ne postoji.")

3. Pisanje u CSV fajl

Modul csv olakšava rad sa tabelarnim podacima u tekstualnom obliku, gde su vrednosti u okviru reda razdvojene određenim separatorom, najčešće zarezom. Objekat writer se kreira nad otvorenim fajlom, a metoda writerow() upisuje jedan red.

Primer 3 (Upisivanje tabele u CSV fajl): Sačuvati tabelu proizvoda, sa zaglavljem, u CSV fajl. import csv with open("proizvodi.csv", "w", encoding="utf-8", newline="") as fajl: writer = csv.writer(fajl) writer.writerow(["Proizvod", "Količina", "Cena"]) writer.writerow(["Jabuke", 120, 90]) writer.writerow(["Kruške", 85, 110])
Parametar newline="" prilikom otvaranja CSV fajla sprečava pojavu praznih redova između podataka na Windows operativnom sistemu.

4. Čitanje CSV fajla

CSV fajl se čita red po red, pomoću for petlje, slično kao što se obični tekstualni fajl čita liniju po liniju. U svakom prolazu petlje dobija se po jedan red tabele, a oblik u kom se taj red dobija zavisi od toga da li se koristi csv.reader() ili csv.DictReader().

Kod csv.reader() svaki red se dobija kao posebna lista niski, a vrednostima se pristupa preko indeksa. Prvi red fajla (zaglavlje) se čita kao i svaki drugi red.

import csv with open("proizvodi.csv", "r", encoding="utf-8") as fajl: reader = csv.reader(fajl) for red in reader: print(red) # ['Proizvod', 'Količina', 'Cena'] # ['Jabuke', '120', '90'] # ['Kruške', '85', '110']

Kod csv.DictReader() prvi red fajla (zaglavlje) se ne dobija kao red sa podacima, već se njegove vrednosti koriste kao ključevi. Svaki sledeći red se dobija kao poseban rečnik, pa se vrednostima pristupa preko naziva kolone, što je obično preglednije.

Primer 4 (Čitanje CSV fajla pomoću DictReader-a): Učitati tabelu proizvoda iz CSV fajla i ispisati naziv i cenu svakog proizvoda. import csv with open("proizvodi.csv", "r", encoding="utf-8") as fajl: reader = csv.DictReader(fajl) for red in reader: print(red["Proizvod"], "->", red["Cena"], "din.") # Jabuke -> 90 din. # Kruške -> 110 din.
Sve vrednosti iz CSV fajla se čitaju kao niske (npr. '90', a ne 90). Ukoliko je potrebno računati sa njima, prethodno ih treba pretvoriti u broj, na primer pomoću funkcije int().
Zadaci:

1. Napraviti rečnik koji predstavlja knjigu, sa ključevima "naslov", "autor" i "godina", i sačuvati ga u fajl knjiga.json pomoću funkcije dump().

2. Učitati fajl knjiga.json iz prethodnog zadatka pomoću funkcije load() i ispisati naslov i autora knjige. Obraditi slučaj kada fajl ne postoji.

3. Pomoću csv.writer kreirati fajl ocene.csv sa zaglavljem "Ime" i "Ocena" i upisati u njega podatke za tri učenika.

4. Pomoću csv.DictReader učitati fajl ocene.csv iz prethodnog zadatka i za svakog učenika ispisati ime i ocenu (npr. „Ana: 5“).
