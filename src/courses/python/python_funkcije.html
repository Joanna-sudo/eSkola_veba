Funkcije

Funkcija je imenovani blok koda koji izvršava određeni zadatak i može se pozvati (izvršiti) više puta iz različitih delova programa. Korišćenjem funkcija kod postaje pregledniji, kraći i lakši za održavanje, jer se izbegava ponavljanje istih naredbi.

1. Definisanje i pozivanje funkcije

Funkcija se definiše ključnom rečju def, nazivom funkcije i zagradama koje mogu (ali ne moraju) sadržati parametre.

Primer 1 (Jednostavna funkcija): Definisati funkciju koja ispisuje poruku na ekranu, i pozvati je. def pozdrav(): print("Zdravo, svete!") pozdrav() # poziv funkcije

Kod definisanja funkcije, telo funkcije (kod koji se izvršava) mora biti uvučeno (indentovano), kao i kod uslova i petlji. To Python koristi za određivanje granica bloka koda.

Kao i promenljive, funkcije se po zvaničnim preporukama za pisanje Python koda (PEP 8) imenuju u stilu snake_case. Naziv funkcije treba da bude dovoljno opisan da iz njega, bez čitanja koda, bude jasno šta se tačno dešava kada se funkcija pozove. Zato se najčešće koristi glagol koji opisuje radnju (npr. izracunaj_prosek(), posalji_email()), a ne nejasni, uopšteni nazivi poput f() ili obradi().

2. Parametri funkcije

Parametri omogućavaju da se funkciji prosledi vrednost sa kojom će raditi. Prilikom poziva funkcije, ta vrednost se naziva argument.

Primer 2 (Funkcija sa parametrom): Definisati funkciju koja pozdravlja osobu čije se ime prosleđuje kao argument, i pozvati je za dve različite osobe. def pozdravi_osobu(ime): print("Zdravo, " + ime + "!") pozdravi_osobu("Marko") # Zdravo, Marko! pozdravi_osobu("Ana") # Zdravo, Ana!

3. Povratna vrednost - return

Naredba return prekida izvršavanje funkcije i vraća rezultat pozivaocu. Ukoliko funkcija nema naredbu return, ona podrazumevano vraća vrednost None.

Primer 3 (Funkcija koja vraća vrednost): Definisati funkciju koja sabira dva broja i vraća rezultat. def saberi(a, b): return a + b rezultat = saberi(5, 7) print(rezultat) # 12

4. Podrazumevane vrednosti parametara

Parametru je moguće dodeliti podrazumevanu vrednost, koja se koristi ukoliko prilikom poziva funkcije taj argument nije prosleđen.

Primer 4 (Podrazumevani parametar): Definisati funkciju za stepenovanje sa podrazumevanim eksponentom, i pozvati je sa i bez eksplicitno navedenog eksponenta. def stepenuj(broj, eksponent=2): return broj ** eksponent print(stepenuj(5)) # 25 (koristi podrazumevani eksponent 2) print(stepenuj(5, 3)) # 125 (eksponent je eksplicitno prosleđen)

5. Lambda funkcije

Lambda funkcija je kratka, bezimena (anonimna) funkcija, napisana u jednoj liniji, bez naredbe def i bez return (rezultat izraza se vraća automatski). Osnovni oblik izgleda ovako:

lambda parametri: izraz

Primer 5 (Kreiranje i pozivanje lambda funkcije): Napraviti lambda funkciju koja kvadrira zadati broj, i pozvati je. kvadriraj = lambda broj: broj ** 2 print(kvadriraj(5)) # 25
Lambda izraz iznad je kraći zapis sledeće, uobičajeno definisane funkcije:
def kvadriraj(broj):
  return broj ** 2

Lambda funkcija može imati i više parametara, razdvojenih zarezom (npr. lambda a, b: a + b), ali njeno telo mora biti tačno jedan izraz. Za razliku od obične funkcije, u njemu se ne mogu pisati uslovi, petlje ni više naredbi.

Iako se, kao u primeru iznad, lambda funkcija može dodeliti promenljivoj i pozivati po imenu, njena prava svrha je da se koristi tamo gde je funkcija potrebna samo privremeno, na jednom mestu, najčešće kao argument koji se prosleđuje drugoj funkciji, kao što je parametar key kod funkcije sorted() (obrađene u lekciji o listama).

Primer 6 (Sortiranje proizvoda po ceni pomoću lambda funkcije): Listu proizvoda sortirati po ceni, koristeći lambda funkciju kao ključ za sortiranje. proizvodi = [ {"naziv": "Jabuke", "cena": 120}, {"naziv": "Kruške", "cena": 90}, {"naziv": "Grožđe", "cena": 250}, ] sortirano = sorted(proizvodi, key=lambda proizvod: proizvod["cena"]) for proizvod in sortirano: print(proizvod["naziv"], "-", proizvod["cena"])
Izraz lambda proizvod: proizvod["cena"] je kraći zapis funkcije koja bi, definisana na uobičajen način, izgledala ovako:
def po_ceni(proizvod):
  return proizvod["cena"]

6. Rekurzija

Rekurzivna funkcija je funkcija koja, u svom telu, poziva samu sebe. Svaka rekurzivna funkcija mora imati bazni slučaj (uslov pod kojim se poziv zaustavlja), kako bi izbegla beskonačno pozivanje.

Primer 7 (Izračunavanje faktorijela rekurzijom): Napisati rekurzivnu funkciju koja izračunava faktorijel zadatog broja. def faktorijel(n): if n == 0: # bazni slučaj return 1 return n * faktorijel(n - 1) print(faktorijel(5)) # 120 (5 * 4 * 3 * 2 * 1)
Isti zadatak se najčešće može rešiti i običnom (iterativnom) petljom, koja je u Pythonu obično brža i lakša za praćenje. Rekurzija je praktičnija kod problema koji su po prirodi podeljeni na manje, istovrsne probleme (na primer, pretraga stabla direktorijuma).
Zadaci:

1. Napisati funkciju je_prost(broj) koja proverava da li je zadati ceo broj prost i vraća True ili False. Pozvati funkciju za nekoliko različitih brojeva i ispisati rezultate. Zatim napisati i rekurzivnu funkciju suma_do(n), koja izračunava zbir svih celih brojeva od 1 do n.

2. Napisati funkciju najveci(a, b, c) koja vraća najveći od tri prosleđena broja. Pozvati je za nekoliko različitih trojki brojeva i ispisati rezultate.

3. Napisati funkciju pozdrav(ime, poruka="Dobrodošli") sa podrazumevanom vrednošću drugog parametra, koja vraća f-string oblika "Dobrodošli, Ana!". Pozvati je jednom sa oba argumenta i jednom samo sa imenom.
