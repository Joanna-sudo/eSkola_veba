Pozivanje AI modela iz Python koda

Do sada smo pisali programe u kojima smo mi, korak po korak, opisivali šta računar treba da uradi. U ovoj lekciji videćemo kako se iz Python programa može pozvati AI model, odnosno model veštačke inteligencije (engl. Artificial Intelligence, skraćeno AI), koji razume zadatke napisane običnim jezikom, i kako mu se može zadati uloga (na primer: „ti si nastavnik matematike“, „ti si lektor“, „ti si turistički vodič“), koja utiče na to kako će odgovarati.

Kao primer koristićemo modele Gemini kompanije Google, jer imaju besplatan nivo korišćenja (engl. free tier), dovoljan za učenje i vežbu. Princip je isti i kod drugih AI modela (Claude kompanije Anthropic, GPT kompanije OpenAI...): program šalje zahtev (poruku) preko interneta, a model vraća odgovor u obliku teksta, koji se dalje može obrađivati u kodu kao i svaki drugi string.

1. Šta je API i šta je potrebno za rad

AI model se ne nalazi na našem računaru, već na serverima kompanije koja ga je napravila. Programi mu pristupaju preko API-ja (engl. Application Programming Interface), odnosno skupa pravila kako se šalju zahtevi i kako izgledaju odgovori. Da se slanje zahteva preko interneta ne bi pisalo ručno, koristi se gotov paket google-genai, koji se instalira pomoću alata pip (obrađen u lekciji o modulima i paketima).

pip install google-genai

Pored paketa, potreban je i API ključ, tajna šifra po kojoj server zna ko šalje zahtev. Ključ se dobija besplatno, prijavom preko Google naloga na sajt aistudio.google.com/apikey i klikom na dugme Create API key. Za besplatan nivo nije potrebna platna kartica.

Besplatan nivo ima ograničenja: dozvoljen je samo određen broj zahteva u minutu i u toku jednog dana (tačna ograničenja za svaki model mogu se videti u Google AI Studio-u). Takođe, Google podatke poslate kroz besplatan nivo može koristiti za unapređenje svojih proizvoda, pa modelu ne treba slati lične i poverljive podatke.
API ključ je kao lozinka: nikada ga ne treba upisivati direktno u kod, slati drugima ili postavljati na internet (npr. na GitHub), jer bi bilo ko mogao da ga koristi umesto vas. Ključ se čuva u promenljivoj okruženja (engl. environment variable) operativnog sistema pod imenom GEMINI_API_KEY, odakle ga paket google-genai sam pronalazi.

Na Windows-u se promenljiva okruženja trajno postavlja tako što se u terminalu (Command Prompt) izvrši sledeća komanda, pri čemu se umesto teksta vas-kljuc upisuje dobijeni ključ:

setx GEMINI_API_KEY "vas-kljuc"
Nakon izvršavanja komande setx potrebno je zatvoriti i ponovo otvoriti VS Code (i terminal), jer programi novu promenljivu vide tek kada se ponovo pokrenu. Ukoliko je otvoreno više prozora VS Code-a, potrebno je zatvoriti sve prozore, a ne samo onaj u kome se radi. Na macOS-u i Linux-u se umesto komande setx koristi komanda export GEMINI_API_KEY="vas-kljuc". Promenljiva postavljena komandom export važi samo dok traje ta sesija terminala, pa terminal ne treba zatvarati, a program se pokreće iz tog istog terminala. U svakom novom terminalu komandu treba izvršiti ponovo.

2. Prvi poziv AI modela

Komunikacija sa modelom odvija se preko objekta klase Client (klijenta) i njegove metode models.generate_content(), kojoj se prosleđuju dva osnovna parametra:

  • model - naziv modela koji se koristi,
  • contents - tekst (pitanje ili zadatak) koji se šalje modelu.

Tekst odgovora nalazi se u osobini text objekta koji metoda vraća.

Primer 1 (Prvo pitanje za AI model): Postaviti AI modelu jedno pitanje i ispisati odgovor. from google import genai MODEL = "gemini-3.6-flash" klijent = genai.Client() odgovor = klijent.models.generate_content( model=MODEL, contents="Objasni u dve rečenice šta je promenljiva u programiranju.", ) print(odgovor.text)
Naziv modela je namerno smešten u promenljivu MODEL na početku programa. AI modeli se često menjaju: izlaze nove verzije, a stare se posle nekog vremena ukidaju. Kada se to dogodi, dovoljno je izmeniti naziv modela na jednom mestu. Kako se dobija spisak trenutno dostupnih modela, objašnjeno je u poglavlju 7.

3. Zadavanje uloge - sistemska poruka

Uloga se modelu zadaje pomoću sistemske poruke (engl. system instruction). To je uputstvo koje važi za ceo razgovor i koje model poštuje pri svakom odgovoru. U njemu se obično navodi ko je model (uloga), kome se obraća, i kako treba da odgovara (dužina, ton, jezik, format). Sistemska poruka se prosleđuje kroz parametar config, kao objekat klase GenerateContentConfig iz modula types.

Primer 2 (Model u ulozi nastavnika): Zadati modelu ulogu strpljivog nastavnika matematike za učenike petog razreda i postaviti mu pitanje. from google import genai from google.genai import types MODEL = "gemini-3.5-flash-lite" klijent = genai.Client() uloga = ( "Ti si strpljiv nastavnik matematike u osnovnoj školi. " "Obraćaš se učenicima petog razreda, pa koristiš jednostavne reči " "i primere iz svakodnevnog života. Odgovaraš na srpskom jeziku, " "najviše u pet rečenica." ) odgovor = klijent.models.generate_content( model=MODEL, contents="Šta su razlomci?", config=types.GenerateContentConfig(system_instruction=uloga), ) print(odgovor.text)

Najbolji način da se vidi koliko uloga utiče na odgovor je da se isto pitanje postavi modelu u nekoliko različitih uloga. Uloge ćemo čuvati u rečniku (ključ je naziv uloge, a vrednost je sistemska poruka) i proći kroz njega pomoću for petlje.

Primer 3 (Isto pitanje, različite uloge): Postaviti isto pitanje modelu u tri različite uloge i ispisati sve odgovore. from google import genai from google.genai import types MODEL = "gemini-3.5-flash-lite" klijent = genai.Client() uloge = { "Naučnik": "Ti si fizičar. Odgovaraš stručno i precizno, u najviše tri rečenice.", "Pesnik": "Ti si pesnik. Na svako pitanje odgovaraš kratkom pesmom od četiri stiha.", "Vaspitačica": "Ti si vaspitačica u vrtiću. Odgovaraš tako da razume dete od pet godina, u najviše tri rečenice.", } pitanje = "Zašto je nebo plavo?" for naziv, uloga in uloge.items(): odgovor = klijent.models.generate_content( model=MODEL, contents=pitanje, config=types.GenerateContentConfig(system_instruction=uloga), ) print("---", naziv, "---") print(odgovor.text) print()

4. Funkcija za pozivanje AI modela

Pošto se isti kod za slanje zahteva ponavlja, zgodno ga je smestiti u funkciju (obrađene u ranijoj lekciji), koja kao parametre prima ulogu i pitanje, a vraća tekst odgovora.

Primer 4 (Funkcija pitaj_ai): Napisati funkciju koja za zadatu ulogu i pitanje vraća odgovor modela kao string. from google import genai from google.genai import types MODEL = "gemini-3.5-flash-lite" klijent = genai.Client() def pitaj_ai(uloga, pitanje): odgovor = klijent.models.generate_content( model=MODEL, contents=pitanje, config=types.GenerateContentConfig(system_instruction=uloga), ) return odgovor.text prevodilac = "Ti si prevodilac. Svaki tekst koji dobiješ prevodiš na engleski jezik i vraćaš samo prevod, bez objašnjenja." print(pitaj_ai(prevodilac, "Dobar dan, kako ste?")) kuvar = "Ti si kuvar. Za zadate namirnice predlažeš jedno jednostavno jelo i ukratko opisuješ pripremu." print(pitaj_ai(kuvar, "Imam jaja, krompir i luk."))

5. Razgovor u više koraka (čet)

AI model ne pamti prethodne zahteve: svaki poziv metode generate_content() je za njega potpuno nov. Da bi model „znao“ šta je ranije rečeno, pri svakom novom pitanju mu se mora poslati cela istorija razgovora. Paket google-genai to radi umesto nas pomoću objekta chat, koji se pravi metodom chats.create(). Čet sam čuva istoriju, a nova poruka se šalje metodom send_message().

Primer 5 (Čet sa modelom u ulozi turističkog vodiča): Napraviti program u kome korisnik razgovara sa modelom u ulozi turističkog vodiča, sve dok ne ukuca reč „kraj“. from google import genai from google.genai import types MODEL = "gemini-3.5-flash-lite" klijent = genai.Client() uloga = ( "Ti si ljubazan turistički vodič kroz Srbiju. " "Preporučuješ mesta za obilazak, hranu i zanimljivosti. " "Odgovaraš kratko, u najviše četiri rečenice." ) cet = klijent.chats.create( model=MODEL, config=types.GenerateContentConfig(system_instruction=uloga), ) while True: pitanje = input("Vi: ") if pitanje == "kraj": break odgovor = cet.send_message(pitanje) print("Vodič:", odgovor.text)
Zahvaljujući istoriji koju čet čuva, na pitanje „A šta da jedem tamo?“ model zna na koje se mesto odnosi reč „tamo“. Treba imati na umu da se istorija šalje pri svakom pitanju, pa duži razgovor brže troši ograničenja besplatnog nivoa.

6. Obrada teksta iz fajla

Prava snaga ovog pristupa vidi se kada se AI model kombinuje sa onim što smo već naučili, na primer sa čitanjem i upisom u fajlove. Program može da pročita tekst iz fajla, prosledi ga modelu sa odgovarajućom ulogom, i rezultat sačuva u novi fajl, bez ikakvog ručnog rada.

Primer 6 (Model u ulozi lektora): U folderu u kojem se nalazi program, kreirati fajl sastav.txt i u njega upisati nekoliko rečenica sa namerno napravljenim pravopisnim i gramatičkim greškama. Napisati program koji će pročitati tekst iz fajla sastav.txt, dati ga modelu u ulozi lektora i ispravljen tekst sačuvati u fajl sastav_ispravljen.txt. from google import genai from google.genai import types MODEL = "gemini-3.5-flash-lite" klijent = genai.Client() uloga = ( "Ti si lektor srpskog jezika. Ispravljaš pravopisne i gramatičke " "greške u tekstu koji dobiješ, ne menjaš smisao i stil teksta, " "i vraćaš isključivo ispravljen tekst, bez ikakvih komentara." ) with open("sastav.txt", "r", encoding="utf-8") as fajl: tekst = fajl.read() odgovor = klijent.models.generate_content( model=MODEL, contents=tekst, config=types.GenerateContentConfig(system_instruction=uloga), ) with open("sastav_ispravljen.txt", "w", encoding="utf-8") as fajl: fajl.write(odgovor.text) print("Ispravljen tekst je sačuvan u fajl sastav_ispravljen.txt")
Kada se odgovor modela dalje koristi u programu (upisuje u fajl, obrađuje...), u ulozi je važno jasno naglasiti da model vrati samo traženi rezultat, bez uvoda poput „Evo ispravljenog teksta:“. Takođe, treba imati na umu da model može da pogreši, pa je rezultat uvek dobro proveriti.

7. Spisak trenutno dostupnih modela

Kompanije koje prave AI modele redovno izbacuju nove verzije, a stare posle nekog vremena mogu da povuku iz upotrebe. Zato naziv modela koji danas radi (npr. gemini-3.5-flash-lite) za nekoliko meseci možda više neće postojati. Umesto nagađanja, spisak trenutno dostupnih modela može se dobiti direktno iz koda: skoro svaki AI servis ima metodu models.list(), koja vraća sve modele dostupne sa datim API ključem.

Primer 7 (Spisak svih Gemini modela): Ispisati nazive svih Gemini modela dostupnih sa datim API ključem. from google import genai klijent = genai.Client() for model in klijent.models.list(): print(model.name, "-", model.display_name)
Nazivi se ispisuju sa prefiksom models/ (npr. models/gemini-3.5-flash-lite), a u kodu se navodi deo posle prefiksa.

Spisak dobijen u prethodnom primeru sadrži modele različitih namena, na primer modele za pretvaranje teksta u govor ili obradu zvuka. Svaki model u listi supported_actions navodi koje akcije podržava. Ako želimo da izdvojimo samo modele koji podržavaju generisanje sadržaja (generateContent), možemo ih izdvojiti pomoću uslova if.

Primer 8 (Spisak Gemini modela koji generišu sadržaj): Ispisati nazive samo onih Gemini modela koji mogu da generišu sadržaj. from google import genai klijent = genai.Client() for model in klijent.models.list(): if "generateContent" in model.supported_actions: print(model.name, "-", model.display_name)
Koji od ovih modela su besplatni, može se proveriti na stranici ai.google.dev/gemini-api/docs/pricing.
Spisak aktuelnih modela, zajedno sa cenama i datumima ukidanja starih modela, može se pogledati i na zvaničnim stranicama kompanija: Gemini modeli, Claude modeli i OpenAI modeli. Ko želi da isproba i modele drugih kompanija, na tim stranicama može da proveri uslove korišćenja i da li nude neku besplatnu opciju.

8. Kod je radio, a sada ne radi - zašto?

Kod programa koji koriste AI modele često se dešava da program koji je juče ispravno radio danas prijavi grešku, iako u kodu ništa nije menjano. Pre nego što se krene u traženje greške u kodu, treba znati da su najčešći razlozi za to sledeći:

1. Iskorišćeno je ograničenje (kvota) besplatnog nivoa. Poslato je više zahteva nego što je dozvoljeno u minutu ili u toku dana. Server tada vraća grešku sa kodom 429 (RESOURCE_EXHAUSTED). Rešenje: sačekati minut (ako je prekoračeno ograničenje u minutu), ili sačekati sledeći dan. Drugo rešenje je privremeno preći na neki drugi besplatan model, koji ima svoje posebno ograničenje.

2. Model koji koristimo više nije dostupan. Model je ukinut ili mu je promenjen naziv. Server tada vraća grešku u čijoj poruci piše da model nije pronađen (engl. is not found). Ista greška se dobija i kada je naziv modela pogrešno otkucan. Rešenje: pomoću koda iz poglavlja 7 pronaći naziv nekog aktuelnog modela i upisati ga u promenljivu MODEL.

Greška zbog nedostupnog modela ima kod 404 (NOT_FOUND), ali taj kod znači samo da nešto što je traženo nije pronađeno, pa se može javiti i iz drugih razloga. Zato se uzrok ne određuje samo na osnovu koda, već se čita i poruka servera.

Ostale greške su ređe, na primer neispravan API ključ ili privremeni problem na serveru. Za njih je najbolje ispisati kod i poruku koju je server poslao, jer poruka obično sama objašnjava šta nije u redu. Spisak svih kodova grešaka nalazi se na stranici ai.google.dev/gemini-api/docs/generate-content/api-errors.

Da bi korisnik umesto dugačke poruke o grešci dobio jasno objašnjenje, poziv modela se stavlja u try/except blok (obrađen u lekciji o izuzecima). Paket google-genai sve greške koje vrati server podiže kao izuzetak APIError. Kod greške se nalazi u osobini code, a poruka servera u osobini message. Ukoliko nema internet veze, zahtev ne stiže do servera, pa se javlja greška druge vrste, koju naredni primer ne obrađuje.

Primer 9 (Obrada grešaka pri pozivu modela): Pozvati model i, ukoliko dođe do greške, za iskorišćeno ograničenje ispisati razumljivo objašnjenje, a za ostale greške kod i poruku servera. from google import genai from google.genai import types, errors MODEL = "gemini-3.8-flash" klijent = genai.Client() try: odgovor = klijent.models.generate_content( model=MODEL, contents="Opiši gol u poslednjem minutu utakmice.", config=types.GenerateContentConfig( system_instruction="Ti si sportski komentator. Odgovaraš uzbuđeno, u dve rečenice." ), ) print(odgovor.text) except errors.APIError as greska: if greska.code == 429: print("Iskorišćeno je ograničenje besplatnog nivoa.") print("Sačekajte minut ili do sutra, ili promenite model.") else: print("Greška", greska.code, ":", greska.message)
Ukoliko promenljiva okruženja GEMINI_API_KEY uopšte nije postavljena, greška se javlja već pri pravljenju klijenta (genai.Client()), sa porukom da API ključ nije pronađen. U tom slučaju treba proveriti korak iz prvog poglavlja, zatvoriti sve otvorene prozore VS Code-a i ponovo ga pokrenuti.
