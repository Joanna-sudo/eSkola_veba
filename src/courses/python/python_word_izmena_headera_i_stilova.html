Izmena header-a i stilova u Word dokumentu

U prethodnoj lekciji naučili smo kako da čitamo sadržaj Word dokumenta pomoću biblioteke python-docx. Sada ćemo videti kako se taj isti dokument može automatski izmeniti, konkretno, kako se menja tekst u zaglavlju (header-u) stranice, kao i kako se menja tekst samo onih pasusa koji su napisani određenim stilom (na primer, samo naslova).

Svi primeri u ovoj lekciji nastavljaju rad nad istim dokumentom, izvestaj.docx, opisanim u prethodnoj lekciji (može se preuzeti na istom mestu izvestaj.docx).

1. Izmena zaglavlja (header-a) dokumenta

Word dokument je podeljen na jednu ili više sekcija (sections), a svaka sekcija ima svoje zaglavlje. Kod jednostavnijih dokumenata najčešće postoji samo jedna sekcija, pa se do zaglavlja dolazi preko dokument.sections[0].header. Zaglavlje, kao i telo dokumenta, sadrži paragrafe.

Primer 1 (Izmena teksta u zaglavlju): Izmeniti tekst zaglavlja dokumenta i sačuvati rezultat kao novi fajl. from docx import Document dokument = Document("izvestaj.docx") header = dokument.sections[0].header header.paragraphs[0].text = "Interni izveštaj - poverljivo" dokument.save("izvestaj_izmenjen.docx")
Metoda save() čuva izmene u novi (ili isti) .docx fajl. Ukoliko se prosledi isto ime kao originalni fajl, on će biti pregažen, zato je za vežbu bezbednije čuvati rezultat pod novim imenom, kao u primeru iznad.

Ukoliko zaglavlje ne sadrži nijedan paragraf (prazno je), pre upisa teksta potrebno je prvo dodati paragraf pomoću metode add_paragraph().

Primer 2 (Dodavanje paragrafa u prazno zaglavlje): Postaviti tekst u zaglavlje koje trenutno nema nijedan paragraf. from docx import Document dokument = Document("izvestaj.docx") header = dokument.sections[0].header if len(header.paragraphs) == 0 or header.paragraphs[0].text == "": header.paragraphs[0].text = "Naziv firme d.o.o." dokument.save("izvestaj.docx")
Dokument se ovde ponovo učitava sa diska (umesto nastavka rada nad dokument promenljivom iz Primera 1), kako bi se radilo nad originalnim, praznim zaglavljem. Da se dokument nije ponovo učitao, zaglavlje bi već sadržalo tekst upisan u Primeru 1, uslov bi bio netačan i ništa se ne bi izmenilo. Takođe je dodat i poziv metode save(), ovoga puta nad originalnim fajlom. Bez save() bi izmena ostala samo u memoriji i ne bi bila vidljiva nakon završetka programa.

2. Stilovi paragrafa

Svaki paragraf u Word dokumentu ima dodeljen stil (npr. „Normal“, „Heading 1“, „Heading 2“, „Title“...), koji određuje njegov izgled - font, veličinu, boju i slično. Naziv stila datog paragrafa dobija se preko osobine paragraf.style.name.

Primer 3 (Ispis stila svakog paragrafa): Za svaki paragraf dokumenta ispisati naziv njegovog stila i tekst. from docx import Document dokument = Document("izvestaj.docx") for paragraf in dokument.paragraphs: print(paragraf.style.name, "->", paragraf.text)

3. Izmena teksta samo u pasusima određenog stila

Kombinovanjem provere stila (uslovni izraz if, obrađen u ranijoj lekciji) i izmene teksta, moguće je automatski izmeniti samo one pasuse koji su napisani određenim stilom - na primer, dodati prefiks svim naslovima nivoa 1 (Heading 1), bez diranja ostatka teksta.

Primer 4 (Izmena naslova stila Heading 1): Svim paragrafima stila Heading 1 dodati prefiks, bez izmene ostatka teksta. from docx import Document dokument = Document("izvestaj.docx") for paragraf in dokument.paragraphs: if paragraf.style.name == "Heading 1": paragraf.text = "POGLAVLJE: " + paragraf.text dokument.save("izvestaj_izmenjen.docx")
Stil važi za ceo pasus, ali se deo pasusa može i dodatno formatirati (npr. podebljati samo jedna reč). Zato Word tekst pasusa čuva u delovima koji se nazivaju run, pri čemu svi karakteri jednog run-a imaju isto formatiranje. Na primer, u dokumentu izvestaj.docx pasus „Ovaj izveštaj sadrži pregled poslovnih rezultata kompanije za 2023. godinu.“ sastoji se od tri run-a: „Ovaj izveštaj sadrži pregled poslovnih rezultata kompanije za “, „2023“ (podebljano) i „. godinu.“.

Izmena osobine paragraf.text zamenjuje sve run-ove jednim novim, pa se dodatno formatiranje unutar pasusa gubi. Da bi se ono sačuvalo, menja se tekst pojedinačnog run-a preko liste paragraf.runs, kao u narednom primeru.
Primer 5 (Zamena reči unutar pasusa uz očuvanje formatiranja): U pasusima stila Normal zameniti jednu reč drugom, bez gubljenja formatiranja. from docx import Document dokument = Document("izvestaj.docx") for paragraf in dokument.paragraphs: if paragraf.style.name == "Normal": for run in paragraf.runs: if "2023" in run.text: run.text = run.text.replace("2023", "2024") dokument.save("izvestaj_izmenjen.docx")
Word ponekad i jednu reč podeli na više run-ova (npr. „20“ i „23“). U tom slučaju tražena reč se ne nalazi ni u jednom run-u, pa do zamene neće doći.

4. Izmena zaglavlja u više fajlova odjednom

Do sada je svaki primer radio nad jednim dokumentom. U praksi je često potrebno primeniti istu izmenu na više Word dokumenata odjednom, koji se nalaze u istom folderu. Za dobijanje spiska svih fajlova u folderu koristi se ugrađeni modul os, konkretno funkcija os.listdir().

Za vežbu, kreirati folder (npr. pod nazivom dokumenti) i u njega staviti nekoliko .docx fajlova. Mogu se iskoristiti već poznati izvestaj.docx i izvestaj_izmenjen.docx iz prethodnih primera, a po želji dodati i još poneki .docx fajl.
Primer 6 (Izmena zaglavlja u svim dokumentima iz foldera): Za svaki .docx fajl u folderu izmeniti tekst zaglavlja i sačuvati izmenu. import os from docx import Document folder = "dokumenti" for naziv_fajla in os.listdir(folder): if naziv_fajla.endswith(".docx"): putanja = os.path.join(folder, naziv_fajla) dokument = Document(putanja) header = dokument.sections[0].header header.paragraphs[0].text = "Interni izveštaj - poverljivo" dokument.save(putanja) print("Izmenjen fajl:", naziv_fajla)
Funkcija os.listdir(folder) vraća listu naziva svih fajlova (i podfoldera) u datom folderu, bez pune putanje. Zato se puna putanja do fajla gradi pomoću os.path.join(folder, naziv_fajla), koja ispravno spaja folder i naziv fajla bez obzira na operativni sistem.
Zadaci:

1. Kreirati Word dokument koji sadrži zaglavlje, jedan naslov (stil Heading 1) i nekoliko pasusa običnog teksta (stil Normal). Napisati Python program koji: a) u zaglavlje upisuje vaše ime i prezime, b) svim naslovima dodaje prefiks "TEMA: ", i v) čuva rezultat kao novi .docx fajl.

2. Napisati program koji za dokument izvestaj.docx prebrojava koliko paragrafa ima stil Heading 1, a koliko stil Normal, i ispisuje oba broja.

3. Napisati program koji u svim paragrafima stila Normal zamenjuje jednu reč drugom (npr. "firma" rečju "kompanija"), čuvajući formatiranje (izmenom preko liste runs), a zatim rezultat čuva kao novi .docx fajl.
