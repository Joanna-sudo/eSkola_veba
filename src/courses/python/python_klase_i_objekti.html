Klase i objekti

Python podržava objektno orijentisano programiranje (skraćeno OOP). OOP je pristup programiranju u kom se podaci i funkcije koje nad njima rade grupišu zajedno u jednu celinu koja se naziva klasa. Do sada su podaci (npr. naziv i cena proizvoda) i funkcije koje ih obrađuju bili odvojeni jedni od drugih; klase omogućavaju da se povežu u jednu smislenu celinu.

1. Definisanje klase

Klasa se definiše ključnom rečju class i predstavlja svojevrsan „nacrt“ ili šablon, na osnovu kog se kasnije prave konkretni objekti (instance te klase).

Primer 1 (Definisanje klase i kreiranje objekta): Definisati praznu klasu i napraviti jedan njen objekat. class Proizvod: pass p1 = Proizvod() # kreiranje objekta klase Proizvod print(type(p1)) # <class '__main__.Proizvod'>
Po zvaničnim preporukama za pisanje Python koda (PEP 8), naziv klase se piše u stilu PascalCase, odnosno svaka reč u nazivu počinje velikim slovom, bez donje crte između njih (npr. Proizvod, RadniNalog). Promenljive i funkcije se, kao što je opisano u lekciji o promenljivama, imenuju drugačije, u stilu snake_case.

2. Konstruktor i atributi

Funkcije koje su definisane unutar klase nazivaju se metode, a podaci koje svaki objekat te klase poseduje nazivaju se atributi. Posebna metoda __init__() naziva se konstruktor i automatski se poziva prilikom kreiranja objekta. U njoj se najčešće postavljaju početne vrednosti atributa. Prvi parametar svake metode je self i predstavlja sam objekat nad kojim se metoda poziva.

Primer 2 (Konstruktor sa atributima): Definisati klasu proizvoda sa atributima naziv i cena, i ispisati vrednosti tih atributa. class Proizvod: def __init__(self, naziv, cena): self.naziv = naziv self.cena = cena p1 = Proizvod("Jabuke", 120) print(p1.naziv) # Jabuke print(p1.cena) # 120
self se ne prosleđuje eksplicitno prilikom poziva (Proizvod("Jabuke", 120) ima dva argumenta, iako konstruktor prima tri parametra). Python ga automatski prosleđuje kao referencu na objekat koji se upravo kreira.

3. Metode

Osim konstruktora, klasa može sadržati i druge metode. One se definišu na isti način kao obične funkcije, a najčešće rade sa atributima objekta nad kojim su pozvane (preko self). Metoda može na osnovu atributa izračunati i vratiti neku vrednost, ali može i promeniti vrednost atributa, čime se menja stanje samog objekta.

Primer 3 (Dodavanje metoda klasi): Klasi proizvoda dodati metodu koja izračunava ukupnu vrednost na osnovu cene i količine, kao i metodu koja smanjuje količinu proizvoda nakon prodaje. class Proizvod: def __init__(self, naziv, cena, kolicina): self.naziv = naziv self.cena = cena self.kolicina = kolicina def ukupna_vrednost(self): return self.cena * self.kolicina def prodaj(self, n): self.kolicina = self.kolicina - n # menja se atribut objekta p1 = Proizvod("Jabuke", 120, 5) print(p1.ukupna_vrednost()) # 600 p1.prodaj(2) print(p1.kolicina) # 3 print(p1.ukupna_vrednost()) # 360

4. Više objekata iste klase

Od jedne klase moguće je napraviti proizvoljan broj objekata, od kojih svaki ima svoje, nezavisne vrednosti atributa. U primeru se koristi klasa Proizvod iz Primera 3.

Primer 4 (Rad sa više objekata): Napraviti listu od dva objekta klase Proizvod i za svaki ispisati naziv i ukupnu vrednost. proizvodi = [ Proizvod("Jabuke", 120, 5), # kreira se prvi objekat Proizvod("Kruške", 150, 3), # kreira se drugi objekat ] for proizvod in proizvodi: print(proizvod.naziv, "->", proizvod.ukupna_vrednost())

5. Atributi klase i atributi objekta

Atributi koji su do sada korišćeni postavljaju se preko self (npr. self.naziv) i nazivaju se atributi objekta (instance). Upravo zato svaki objekat ima svoje vrednosti, kao u prethodnom primeru. Ponekad je, međutim, potrebna vrednost koja je ista za sve objekte. Takav atribut definiše se direktno u telu klase, van bilo koje metode, i naziva se atribut klase.

Primer 5 (Atribut klase i atributi objekta): Klasi proizvoda dodati atribut klase valuta, koji je isti za sve proizvode. class Proizvod: valuta = "RSD" # atribut klase - zajednički za sve objekte def __init__(self, naziv, cena): self.naziv = naziv # atribut objekta - svaki objekat ima svoju vrednost self.cena = cena # atribut objekta - svaki objekat ima svoju vrednost p1 = Proizvod("Jabuke", 120) p2 = Proizvod("Kruške", 150) print(p1.naziv, p1.cena, p1.valuta) # Jabuke 120 RSD print(p2.naziv, p2.cena, p2.valuta) # Kruške 150 RSD print(Proizvod.valuta) # RSD
Atributu klase može se pristupiti i preko naziva klase (Proizvod.valuta) i preko bilo kog njenog objekta (p1.valuta). Atributi objekta postoje tek kada se objekat kreira, pa im se pristupa samo preko objekta.
