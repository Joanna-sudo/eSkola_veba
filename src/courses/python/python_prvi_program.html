Prvi Python program

Najjednostavniji način da se isproba da li Python radi jeste da se napiše program koji ispisuje poruku na ekranu.

Primer 1 (Ispisivanje poruke na ekranu): Ispisati poruku „Zdravo, svete!“ na ekranu.

Kao što je ranije naglašeno, kod se može pisati u raznim editorima. U okviru ovog kursa biće prikazan rad u Visual Studio Code-u. Za potrebe primera je na Desktopu unapred kreiran prazan folder pod nazivom PYTHON_FOLDER, u kom ćemo čuvati fajlove sa kodom. Nakon pokretanja VS Code-a, otvara se početni (Welcome) ekran, na kom se klikom na opciju Open Folder... bira i otvara taj folder:

Kada je folder otvoren, u panelu Explorer se klikom na ikonicu New File... kreira novi fajl:

Kod se čuva u fajlu sa ekstenzijom .py, na primer prvi_program.py. Nakon što je fajl kreiran, u njemu kucamo naš prvi program, koji treba da ispiše tekst Zdravo, svete! na ekranu. Za ispisivanje se koristi ugrađena funkcija print(), kojoj se u zagradama prosleđuje ono što želimo da se ispiše. U ovom slučaju to je tekst, pa se zapisuje pod znacima navoda:

print("Zdravo, svete!")
Funkcije su imenovani delovi koda koji obavljaju određeni zadatak i mogu se pozvati (izvršiti) navođenjem njihovog imena praćenog zagradama (). Unutar tih zagrada funkciji se mogu proslediti podaci potrebni za njeno izvršavanje, koje nazivamo argumentima. Python sadrži veliki broj ugrađenih funkcija (built-in functions), poput funkcije print(), koje su uvek dostupne i ne moraju se posebno definisati pre upotrebe.
Za razliku od nekih drugih programskih jezika (npr. C ili Java), Python ne zahteva postojanje posebne funkcije main od koje mora da počne izvršavanje programa. Naredbe se izvršavaju redom, od vrha ka dnu fajla, onim redosledom kojim su napisane.

Na slici ispod je prikazano kako sačuvan fajl izgleda otvoren u editoru Visual Studio Code:

Napisan program se može pokrenuti na više načina:

1. Klikom na dugme Run

Najjednostavniji način je da se, dok je otvoren fajl koji želimo da pokrenemo, klikne na dugme Run ( ), koje se tada nalazi u gornjem desnom uglu editora, bez potrebe za ručnim unošenjem komande.

2. Preko terminala

Alternativno, program se može pokrenuti i preko terminala. Integrisani terminal se u Visual Studio Code-u otvara preko menija Terminal > New Terminal:

U terminalu se zatim, iz foldera u kom se fajl nalazi, unosi komanda:

python prvi_program.py

Dobra praksa (best practice) prilikom rada na Python projektima je da se za svaki projekat kreira posebno virtuelno okruženje (venv), koje izoluje biblioteke i verziju Pythona korišćenu u tom projektu od ostatka sistema.

Virtuelno okruženje se može kreirati preko terminala, komandama koje su opisane na zvaničnom sajtu code.visualstudio.com/docs/python/python-tutorial. Nakon aktiviranja, pored putanje u terminalu se prikazuje naziv okruženja (npr. (.venv)), a program se pokreće na isti način kao i pre. Kao rezultat, u konzoli se ispisuje tekst Zdravo, svete!, kao na slici ispod:

Virtuelno okruženje se može kreirati i preko instalirane Python ekstenzije tako što se u panelu Environment Managers klikne na znak + pored opcije venv, dok je u Visual Studio Code-u otvoren folder u kom se želi raditi, nakon čega se bira način kreiranja okruženja. Opcija Quick Create omogućava brzo kreiranje okruženja sa podrazumevanim podešavanjima (biramo ovu opciju), dok Custom omogućava ručni izbor verzije Pythona, lokacije i drugih opcija:

Python takođe podržava i interaktivni režim rada. Ukoliko se u komandnoj liniji samo unese komanda python (bez naziva fajla), otvara se interpreter u kom se naredbe unose i izvršavaju jedna po jedna, odmah nakon pritiska tastera Enter. Ovakav režim je koristan za brzo isprobavanje kratkih delova koda.
Primer 2 (Komentari u kodu): Dodati jednolinijski i višelinijski komentar uz naredbu koja ispisuje poruku na ekranu. # ovo je jednolinijski komentar print("Zdravo, svete!") # komentar može stajati i na kraju linije """ Ovo je višelinijski komentar """

Komentari služe za dodatna objašnjenja u kodu, kako nama samima tako i drugima koji kasnije budu gledali taj kod, a interpreter ih u potpunosti zanemaruje prilikom izvršavanja programa. Jednolinijski komentar počinje znakom #, a sve što se nalazi u tom redu nakon te tarabe smatra se komentarom. Za višelinijske komentare koriste se tri navodnika """ na početku i na kraju, pri čemu se sve što se nalazi između njih, bez obzira na broj redova, smatra komentarom.

U narednim lekcijama više nećemo prikazivati snimke ekrana editora Visual Studio Code, ali podrazumeva se da se kod i dalje piše i pokreće na isti način, kucanjem u fajlu sa ekstenzijom .py i pokretanjem preko terminala.
Zadatak: Napisati program koji ispisuje vaše ime, prezime i grad u kom živite.
