Petlje

Petlje omogućavaju da se određeni deo koda izvrši više puta uzastopno. Python nudi dve vrste petlji: for i while.

1. Petlja for

Petlja for se koristi kada unapred znamo kroz koliko elemenata (ili koliko puta) treba proći. Često se kombinuje sa funkcijom range(), koja generiše niz brojeva.

Primer 1 (Petlja for sa range()): Pomoću petlje ispisati brojeve od 0 do 4. for i in range(5): print(i) # ispisuje brojeve 0, 1, 2, 3, 4
range(n) generiše brojeve od 0 do n-1.
range(a, b) generiše brojeve od a do b-1.
range(a, b, korak) generiše brojeve od a do b-1, uz zadati korak.

Petlja for se u Pythonu često koristi i za direktan prolazak kroz elemente kolekcije (liste, niske...), bez potrebe za brojačem.

Primer 2 (Prolazak kroz karaktere niske): Ispisati svaki karakter niske u posebnom redu. ime = "Python" for karakter in ime: print(karakter)

2. Petlja while

Petlja while izvršava kod sve dok je zadati uslov tačan. Koristi se kada unapred ne znamo tačan broj ponavljanja. Osnovni oblik izgleda ovako:

while uslov:
    naredba

Primer 3 (Petlja while): Pomoću promenljive brojac, koja se u svakom krugu petlje uvećava za 1, ispisati koji je trenutni krug petlje (ukupno pet krugova). brojac = 0 while brojac < 5: print("Krug broj", brojac) brojac += 1

Uslov while petlje se iznova proverava pre svakog narednog kruga, pa se mora obavezno voditi računa da se unutar njenog tela na neki način menja promenljiva od koje uslov zavisi (u primeru iznad: brojac += 1). Da te linije nema, promenljiva brojac bi u svakom krugu ostala 0, uslov brojac < 5 bi zauvek bio tačan, i petlja se nikada ne bi završila, odnosno program bi se „zaglavio“ i beskonačno ispisivao Krug broj 0. Ovakva greška naziva se beskonačna petlja, a program iz nje mora ručno da se prekine (npr. kombinacijom tastera Ctrl+C u terminalu).

Za razliku od nekih drugih jezika (npr. C, Java), Python nema posebnu do-while petlju, kod koje bi se telo petlje izvršilo bar jednom pre prve provere uslova. Isti efekat se u Pythonu postiže petljom while True (uslov koji je uvek tačan), iz koje se izlazi naredbom break, čim uslov za kraj bude ispunjen. Primer sledi na kraju ove lekcije, nakon što break bude objašnjen.

3. Ugnježdene petlje

Petlja može sadržati drugu petlju unutar sebe. Takve petlje se nazivaju ugnježdene petlje. Za svaki krug spoljašnje petlje, unutrašnja petlja se u potpunosti izvrši, od početka do kraja.

Primer 4 (Ugnježdene petlje): Pomoću ugnježdenih for petlji ispisati malu tablicu množenja, za brojeve od 1 do 3. for i in range(1, 4): for j in range(1, 4): print(i, "x", j, "=", i * j)
Unutrašnja petlja mora biti dodatno uvučena u odnosu na spoljašnju, jer uvlačenje određuje kom bloku koda ona pripada. Za svaku vrednost promenljive i (1, 2, 3) unutrašnja petlja prođe kroz sve vrednosti promenljive j (1, 2, 3), pa se ukupno izvrši 3 × 3 = 9 krugova.

4. Naredbe break i continue

Naredba break odmah prekida izvršavanje petlje, čak i ako uslov za njen kraj još nije ispunjen - izvršavanje programa nastavlja se od prve naredbe koja se nalazi posle petlje. Naredba continue ne prekida celu petlju, već samo preskače ostatak koda u tekućoj iteraciji i nastavlja sa sledećom.

Primer 5 (break i continue): Ispisati neparne brojeve od 1 do 10, uz prekid petlje čim broj dostigne 6. for broj in range(1, 11): if broj == 6: break # kada se stigne do toga da broj ima vrednost 6, petlja se odmah prekida i prelazi se na red za ispis "Petlja je završena." if broj % 2 == 0: continue # preskače se samo ispis ovog broja, petlja ide dalje print(broj) print("Petlja je završena.") # ispisuje: 1, 3, 5, a zatim Petlja je završena.
Kada se izvrši break (u primeru iznad, u trenutku kada broj postane 6), izvršavanje petlje se trenutno prekida i program nastavlja od prve naredbe posle petlje, što je ovde print("Petlja je završena."). Brojevi od 6 do 10 se uopšte ne obrađuju. Naredbom continue se, s druge strane, ne izlazi iz petlje, za svaki parni broj (2, 4...) samo se preskače naredba print(broj), a petlja normalno nastavlja sa sledećim brojem.
Primer 6 (while True): Ispisati brojeve počev od 1, uz proveru uslova za kraj tek nakon ispisa. broj = 1 while True: print(broj) if broj >= 5: break broj += 1 # ispisuje: 1, 2, 3, 4, 5
Naredba if broj >= 5: break se nalazi na kraju tela petlje i predstavlja uslov za izlazak. Petlja se time ponaša kao do-while, telo (ovde print(broj)) se prvo izvrši, a tek posle toga se proverava da li treba stati.
Zadaci:

1. Pomoću for petlje ispisati brojeve od 1 do 20.

2. Pomoću while petlje ispisati brojeve od 10 do 1, u opadajućem redosledu (odbrojavanje unazad).
Uputstvo: promenljivoj brojač postaviti početnu vrednost 10, a zatim je u svakom krugu petlje umanjivati za 1 (operator -=), sve dok ne postane manja od 1.

3. Pomoću ugnježdenih for petlji ispisati tablicu množenja za brojeve od 1 do 5, u redovima oblika i x j = rezultat.

4. Pomoću petlje i naredbe break pronaći i ispisati prvi broj veći od 100 koji je deljiv i sa 3 i sa 7.
