Uslovni izrazi

Uslovni izrazi omogućavaju da program izvrši različite delove koda u zavisnosti od toga da li je neki uslov ispunjen. U Pythonu se za to koriste ključne reči if, elif i else.

Osnovni oblik uslovnog izraza izgleda ovako:

if uslov:
    naredba1
elif drugi_uslov:
    naredba2
else:
    naredba3

Za razliku od mnogih drugih jezika, Python ne koristi vitičaste zagrade za obeležavanje bloka koda koji pripada uslovu. Umesto toga, pripadnost bloku se određuje pomoću uvlačenja (indentacije) na početku linije. Za uvlačenje se može koristiti bilo koja količina beline (razmaci ili tabovi), ali je bitno da uvlačenje bude konzistentno unutar istog bloka. Po zvaničnim preporukama za pisanje Python koda (PEP 8) koriste se četiri razmaka po nivou uvlačenja, pa se toga držimo i u nastavku. Nakon uslova (kao i posle else) uvek se piše dvotačka :.

Primer 1 (Jednostavan if uslov): Proveriti da li je osoba punoletna na osnovu njenih godina. godine = 20 if godine >= 18: print("Osoba je punoletna.")

Uvučeni blok koda ispod if izvršava se samo ako je uslov tačan (ima vrednost True); u suprotnom se ceo taj blok preskače.

Primer 2 (if-else naredba): Proveriti da li je zadati broj paran ili neparan. broj = 7 if broj % 2 == 0: print("Broj je paran.") else: print("Broj je neparan.")

Grana else (u prevodu „inače“) navodi se opciono i njen blok se izvršava kada uslov nije ispunjen. Kada je else naveden, uvek se izvrši tačno jedan od dva bloka, ili onaj ispod if, ili onaj ispod else.

Kada je potrebno proveriti više uslova redom, koristi se elif, skraćeno od engleskog „else if“, što u prevodu znači „inače, ako…“. Uslovi se proveravaju od vrha ka dnu, a izvršava se kod ispod prvog uslova koji je ispunjen (svi ostali se preskaču). Ako nijedan uslov nije ispunjen, izvršava se kod u else grani (ako je navedena).

Primer 3 (Ocenjivanje na osnovu broja poena): Na osnovu broja osvojenih poena, pomoću elif grana, odrediti i ispisati ocenu. poeni = 78 if poeni >= 90: ocena = 5 elif poeni >= 75: ocena = 4 elif poeni >= 60: ocena = 3 else: ocena = 2 print("Ocena:", ocena)
Funkcija print() može primiti više vrednosti odvojenih zarezom. Ona ih automatski razdvaja razmakom prilikom ispisa. Na primer poziv print("Broj:", 3) ispisuje Broj: 3.
Zadaci:

1. Napisati program koji na osnovu tri ocene računa prosek i ispisuje da li je učenik položio razred (prosek veći ili jednak 2.5) ili nije.

2. Napisati program koji za zadati ceo broj ispisuje da li je pozitivan, negativan ili jednak nuli.

3. Napisati program koji za zadatu godinu proverava i ispisuje da li je prestupna. Godina je prestupna ako je deljiva sa 4, osim ako je deljiva sa 100 a nije deljiva sa 400.
