Moduli, paketi i pip

Jedna od najvećih prednosti Pythona je ogroman broj gotovih modula i paketa koji rešavaju najrazličitije probleme, od rada sa datumima, preko slanja mejlova, do mašinskog učenja. Zahvaljujući njima nije potrebno sve pisati „od nule“. Pre nego što počnemo da ih koristimo, razjasnićemo šta tačno znači svaki od ovih pojmova.

1. Modul, paket i standardna biblioteka

Modul je datoteka sa ekstenzijom .py koja sadrži Python kod: funkcije, promenljive i klase. Naziv modula je naziv datoteke bez ekstenzije, pa se, na primer, kod iz datoteke racun.py uvozi kao modul racun.

Paket je folder koji objedinjuje više modula (a može sadržati i druge pakete, tzv. podpakete). Preporučuje se da takav folder sadrži datoteku __init__.py, po kojoj Python prepoznaje da je u pitanju paket. Paketi služe da se veći broj srodnih modula organizuje na jednom mestu, slično kao što se datoteke na računaru organizuju u foldere.

geometrija/ <- paket __init__.py krug.py <- modul kvadrat.py <- modul

Moduli iz paketa se uvoze navođenjem naziva paketa i modula, razdvojenih tačkom, na primer import geometrija.krug.

Standardna biblioteka (engl. standard library) je skup modula i paketa koji se instaliraju zajedno sa samim Pythonom, pa su odmah dostupni i ne moraju se posebno preuzimati. Ostali moduli i paketi se nazivaju spoljni (eksterni) i moraju se naknadno instalirati.

2. Korišćenje modula iz standardne biblioteke

Moduli i paketi (kako iz standardne biblioteke, tako i spoljni) se u program uključuju pomoću ključne reči import.

Primer 1 (Korišćenje modula iz standardne biblioteke): Pomoću modula math izračunati kvadratni koren broja i ispisati vrednost broja pi. import math print(math.sqrt(64)) # 8.0 print(math.pi) # 3.141592653589793

Ukoliko je iz modula potrebna samo jedna funkcija, može se uvesti isključivo ona, pomoću from ... import ....

from math import sqrt print(sqrt(81)) # 9.0

3. Instaliranje spoljnih paketa pomoću pip-a

Pored standardne biblioteke, postoji ogroman broj spoljnih paketa koje je razvila zajednica programera. Oni se ne instaliraju automatski sa Pythonom, već se preuzimaju sa zvaničnog repozitorijuma PyPI (Python Package Index) pomoću alata pip, koji se pokreće iz komandne linije, odnosno iz integrisanog terminala, ukoliko se koristi Visual Studio Code (opisano u lekciji o prvom programu).

pip install naziv_paketa

Na primer, paket requests olakšava slanje HTTP zahteva ka veb servisima, a instalira se komandom:

pip install requests

Nakon instalacije, paket se u kodu koristi na isti način kao i moduli iz standardne biblioteke, pomoću naredbe import.

import requests

Komanda pip install se za jedan paket izvršava samo jednom. Paket nakon toga ostaje instaliran, pa ga nije potrebno ponovo instalirati pre svakog pokretanja programa, niti za svaki novi fajl. Naredba import se, s druge strane, piše na početku svakog fajla u kom se paket koristi. Pri tome je važno znati gde se paket instalira: pip ga uvek smešta u ono Python okruženje koje je u tom trenutku aktivno u terminalu.

  • Ukoliko je aktivno virtuelno okruženje projekta (pored putanje u terminalu se vidi npr. (.venv)), paket se instalira samo u to okruženje. Tada je dostupan svim programima tog projekta, ali ne i drugim projektima - u svakom novom virtuelnom okruženju potrebno ga je instalirati ponovo.
  • Ukoliko nijedno virtuelno okruženje nije aktivno, paket se instalira u samu instalaciju Pythona na računaru i dostupan je svim programima koji se pokreću bez virtuelnog okruženja.

Ukoliko se pri pokretanju programa javi greška ModuleNotFoundError za paket koji je već instaliran, najčešći uzrok je to što je paket instaliran u jedno okruženje, a program se pokreće iz drugog. Tada treba aktivirati odgovarajuće okruženje i u njemu ponoviti instalaciju.

Spisak svih trenutno instaliranih paketa se dobija komandom pip list, a određeni paket se uklanja komandom pip uninstall naziv_paketa.

U narednim lekcijama ćemo pomoću pip-a instalirati paket python-docx, koji omogućava da Python program čita i menja sadržaj Word (.docx) dokumenata.

Naziv pod kojim se paket instalira pomoću pip-a ne mora biti isti kao naziv pod kojim se uvozi u kodu. Tako se, na primer, paket za rad sa Word dokumentima instalira komandom pip install python-docx, a u kodu se uvozi kao import docx. Tačan naziv za uvoz se uvek navodi u dokumentaciji paketa.
Zadaci:

1. U komandnoj liniji instalirati paket requests pomoću pip-a, a zatim pomoću komande pip list proveriti da li se paket nalazi na spisku instaliranih paketa.

2. Pomoću modula random iz standardne biblioteke generisati i ispisati pet slučajnih celih brojeva između 1 i 100.

3. Pomoću modula datetime iz standardne biblioteke ispisati današnji datum, a zatim pomoću modula math za zadati decimalni broj ispisati njegovu vrednost zaokruženu nadole (math.floor) i nagore (math.ceil).
