Rad sa niskama (stringovima)

Niska (string, tip str) predstavlja niz karaktera i koristi se za čuvanje teksta. U Pythonu može da se zapiše pod jednostrukim ili dvostrukim navodnicima, bitno je samo da se isti tip navodnika koristi na početku i na kraju.

Primer 1 (Kreiranje niski): Kreirati dve niske, jednu pod jednostrukim, drugu pod dvostrukim navodnicima. ime = 'Petar' poruka = "Zdravo, svete!"

1. Dužina niske i pristup karakterima

Dužina niske (broj karaktera koje sadrži) dobija se pomoću funkcije len(). Pojedinačnom karakteru pristupa se preko indeksa u uglastim zagradama, pri čemu indeksiranje počinje od nule.

Primer 2 (Dužina i indeksiranje): Ispisati dužinu niske, njen prvi i poslednji karakter. tekst = "Python" print(len(tekst)) # 6 - broj karaktera print(tekst[0]) # P - prvi karakter print(tekst[-1]) # n - poslednji karakter

2. Isecanje niske (slicing)

Deo niske se izdvaja pomoću oznake [početak:kraj], pri čemu je početni indeks uključen, a krajnji nije. Ako se niska iseca sve do njenog kraja, indeks kraja se ne mora navesti, dovoljno je napisati [početak:]. Slično, ako isecanje kreće od početka niske, može se izostaviti početni indeks: [:kraj].

Primer 3 (Isecanje niske): Isecanjem izdvojiti prvi i drugi deo niske. tekst = "Programiranje" # niska ima 13 karaktera (indeksi od 0 do 12) print(tekst[0:7]) # Program print(tekst[:7]) # Program - isti rezultat, bez navođenja indeksa početka print(tekst[7:13]) # iranje print(tekst[7:]) # iranje - isti rezultat, bez navođenja indeksa kraja

3. Nadovezivanje i ponavljanje

Dve ili više niski spajaju se u jednu operatorom +. Ovaj postupak se naziva nadovezivanje ili konkatenacija (engl. concatenation). Niska se operatorom * može i ponoviti zadati broj puta.

ime = "Ana" prezime = "Anić" puno_ime = ime + " " + prezime print(puno_ime) # Ana Anić print("-" * 10) # ----------

Operatorom + mogu se spajati samo niske. Ako je potrebno u tekst umetnuti broj (npr. godine ili cenu), on se prvo mora pretvoriti u nisku funkcijom str(), opisanom u lekciji o promenljivama.

Primer (Nadovezivanje broja na tekst): Sastaviti rečenicu koja kombinuje tekst i broj, uz pretvaranje broja u nisku. ime = "Ana" godine = 25 print("Osoba " + ime + " ima " + str(godine) + " godina.") # Osoba Ana ima 25 godina.
Ako se str() izostavi i napiše "... ima " + godine, program se ruši uz grešku TypeError, jer Python ne dozvoljava sabiranje niske i broja. Zbog toga je za umetanje vrednosti u tekst obično praktičnije koristiti f-string (opisan u nastavku), kod kog ovakvo pretvaranje nije potrebno.

4. Korisne metode niski

Metoda je funkcija koja „pripada“ nekom objektu (u ovom slučaju niski) i poziva se tako što se iza vrednosti ili promenljive napiše tačka, pa naziv metode sa zagradama - na primer ime.upper(). O metodama će detaljnije biti reči u lekciji o klasama i objektima; za sada je dovoljno znati da niske imaju ugrađene metode koje olakšavaju najčešće obrade teksta:

  • upper() - pretvara sva slova u velika
  • lower() - pretvara sva slova u mala
  • strip() - uklanja razmake sa početka i kraja niske
  • replace(staro, novo) - vraća novu nisku u kojoj je svaka pojava teksta staro zamenjena tekstom novo; npr. "banana".replace("a", "o") daje "bonono"
  • split(separator) - seče nisku na svakom mestu gde se javlja zadati separator (razdvajač, koji se pri tom uklanja) i vraća listu dobijenih delova; npr. "a,b,c".split(",") daje ["a", "b", "c"]
  • count(podniska) - broji koliko puta se data podniska pojavljuje u okviru niske
Primer 4 (Metode niski): Nad rečenicom primeniti metode za velika slova, zamenu reči, deljenje na reči po razmaku i brojanje pojavljivanja karaktera. recenica = "Python je jednostavan i moćan jezik" print(recenica.upper()) # PYTHON JE JEDNOSTAVAN I MOĆAN JEZIK print(recenica.replace("jednostavan", "zabavan")) # Python je zabavan i moćan jezik print(recenica.split(" ")) # ['Python', 'je', 'jednostavan', 'i', 'moćan', 'jezik'] print(recenica.count("je")) # 3

5. Formatirane niske (f-stringovi)

Za umetanje vrednosti promenljivih direktno u tekst, umesto sabiranja niski operatorom +, praktičnije je koristiti f-string, odnosno nisku koja ispred prvog navodnika ima slovo f, a promenljive se unutar nje pišu u vitičastim zagradama { }.

Primer 5 (Umetanje promenljivih pomoću f-stringa): Pomoću f-stringa ispisati rečenicu koja sadrži ime i godine osobe. ime = "Petar" godine = 30 print(f"{ime} ima {godine} godina.") # Petar ima 30 godina.
Unutar vitičastih zagrada f-stringa mogu se pisati i izrazi, ne samo gole promenljive, na primer f"Za godinu dana biće {godine + 1} godina.".
